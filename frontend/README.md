# Food Finder - frontend

Next.js user interface for the Food Finder application.

See the [project README](../README.md) in the repository root for architecture,
setup instructions and documentation.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Runs on http://localhost:3000 and expects the Express backend on
http://localhost:4000 (configurable via `NEXT_PUBLIC_API_URL`).
